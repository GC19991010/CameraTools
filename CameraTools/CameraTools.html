编辑配置 (JSON)

配置格式说明：
每个配置项是一个对象，包含以下字段：
name — 标签页名称   description — 描述文字   type — "mask"（掩码）或 "command"（命令）

mask 类型需要 mask_props：
{
  "name": "MIVI",
  "description": "小米相机框架日志组",
  "type": "mask",
  "mask_props": {
    "loglevel_cmd": "adb shell setprop persist.vendor.camera.mivi.loglevel 3",
    "mask_cmd": "adb shell setprop persist.vendor.camera.mivi.groupsEnable {mask}"
  },
  "options": [
    { "name": "Mia2LogGroupCore", "bit_value": 1 },
    { "name": "Mia2LogGroupPlugin", "bit_value": 2 }
  ]
}
command 类型每个 option 需要 commands 数组：
{
  "name": "系统调试",
  "description": "常用系统调试开关",
  "type": "command",
  "options": [
    { "name": "开启ADB日志", "commands": ["adb shell setprop log.tag.ADB_DEBUG D"] }
  ]
}
{mask} 会被自动替换为计算后的十六进制掩码值。
